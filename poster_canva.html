Multi-Task NLP Evaluation
Three NLP Tasks on a 10-Sentence Review Test Set: NERC, Sentiment, and Topic Analysis

Tasks & Data

Three tasks evaluated on a gold standard test set: NERC (BIO token tags, 4 entity types), Sentiment (positive / neutral / negative per sentence), and Topic (movie / restaurant / book per sentence). Systems are scored on accuracy and macro-averaged F1 to balance weights across rare classes uniformly.

Test Set
NER-test.tsv - 214 tokens, 10 sentences, tracking PER / ORG / LOC / MISC classes.
Sentiment-topic-test.tsv - same 10 sentences with parallel evaluation layers.
Given the compact test landscape (n = 10), structured qualitative profiling and per-class matrix validation guide our primary insights.
pos 4neu 3neg 3 movie 5restaurant 3book 2
Training Data  ·  topic only
4,500 balanced sentences (1,500 per class): NLTK movie_reviews (movie), Gutenberg corpus (book), and Brown reviews + hobbies (restaurant).
Validated with 5-fold cross-validation. NERC and sentiment use static pre-trained / lexicon modules (no training data collected).
2
Methods
TEXT PREPROCESSINGPIPELINE

NERC: Raw sentence strings are passed directly to both systems, where spaCy handles tokenisation internally. Whereas, NLTK requires POS tagging first. Sentiment: No preprocessing is applied. Both systems use identical thresholds for a fair comparison. Topic: Training sentences were filtered to 5-60 tokens, and stopwords were removed, TF-IDF uses log-normalised term frequencies, capped at 15000 terms.

NAMED ENTITY RECOGNITION2 SYSTEMS

System A: spaCy en_core_web_sm pipeline using a Convolutional Neural Network (CNN) trained on OntoNotes 5. System B: NLTK Maximum Entropy (MaxEnt) token chunker trained on ACE 2004. Output labels are mapped to standard CoNLL BIO tags.

SENTIMENT ANALYSIS2 SYSTEMS

System A: VADER: rule-based lexicon of roughly 7,500 terms with negation, booster, and punctuation heuristics. System B: TextBlob / Pattern lexicon using mean token polarity, thresholded at +/-0.05 to match VADER for a fair comparison.

SUPERVISED TOPIC CLASSIFICATIONSVM

Linear Support Vector Machine (SVM) over a TF-IDF vector space (unigram + bigram, sublinear term frequency, balanced class weights). Trained on the 4,500-sentence corpus and applied to the 10 test sentences.

Qualitative Error Analysis
NER Mismatches

The performance gap comes mainly from label-set differences, not weaker sequence modelling. NLTK's ACE 2004 training has no MISC label, so it routes every nationality to LOC. It also drops honorific titles (Dame, Mr.) and misses out-of-vocabulary names such as the Dutch entity Blauwbrug. spaCy handles MISC and titles better but makes a few boundary errors. spaCy picks up 'Blauwbrug' as a location, but probably because it looks like a proper noun, not because it knows Dutch geography. A lucky correct prediction rather than genuine understanding.

Sentiment Vulnerabilities

Both lexicon systems struggle with context that has no overt sentiment adjective. A single strong word can dominate (e.g. "loved" overriding the rejection in S9). VADER catches strong negatives like "disaster" but is fooled by isolated positives; TextBlob's averaging avoids one VADER false positive (S5) but its narrow adjective lexicon adds two new misses (S0, S8). A single strong word like 'loved' can override clear negative context, while VADER lands the right label on S9, but only because one signal drowned out the rest, not because it understood the sentence.

Topic Corpus Bias

The single error (a book sentence read as movie) is a corpus-composition effect. Because Gutenberg supplies prose FROM books rather than reviews ABOUT books, cues like "novels" never learned a strong book weight. Movie and restaurant sentences are all classified correctly. The SVM has learned to associate actor names and film vocabulary with "movie". The one book error gives it away though: the model recognises Gutenberg-style prose, not what a book review actually sounds like.

5
Discussion & Conclusions
Discussion

Domain mismatch is the single recurring explanation across all three tasks. NLTK loses the entire MISC class because ACE 2004 has no such label. The SVM misclassifies the one book sentence because Gutenberg prose taught it what books sound like, not what reviews about books look like. Both sentiment lexicons misfire on idioms and factual framing their training sources never covered. With spaCy on common PER/ORG/LOC, the SVM on movie and restaurant vocabulary, training domain matches test domain with an high accuracy consistently. Entity types also carry implicit topic signal. For instance, actor names co-occur with movie sentences, restaurant names with restaurant sentences, meaning NER errors could propagate in a chained pipeline.

Conclusion

spaCy substantially outperforms NLTK MaxEnt for NERC (macro-F1 0.85 vs 0.49), driven by the missing MISC label in ACE 2004 and spaCy's full-sentence context window. VADER outperforms TextBlob for sentiment (60% vs 50%), with the advantage coming from broader lexicon coverage of sentiment-bearing nouns like disaster, which TextBlob's adjective-focused Pattern lexicon misses entirely. The SVM topic classifier performs well (90%, CV 75.6%) with one explainable error rooted in training corpus genre mismatch. Across all three tasks, the dominant limiting factor is the same: a gap between where the training data came from and what the test sentences actually look like.

Future Work

The most impactful improvements would be about the training data. Replacing Gutenberg with an Amazon or Goodreads book review corpus and the Brown proxy with Yelp reviews would directly fix the topic classifier's weak point. For NERC, fine-tuning on CoNLL-2003 would close the label schema gap and improve handling of OOV names like Blauwbrug. For sentiment, extending both lexicons with idiomatic multi-word units ("couldn't get into", "forgotten about the") would address the shared failure cases. Longer term, a different fine-tuned transformer would handle context, idiom, and domain shift in ways no lexicon or bag-of-words model can.
