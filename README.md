# G4 Text Mining - Final Assignment

BA Text Mining, VU Amsterdam - Group 4.

Three NLP tasks solved on the provided 10-sentence review test set:

1. **NERC** (token level) - two systems compared: spaCy `en_core_web_sm` (OntoNotes 5) vs NLTK MaxEnt NE Chunker (ACE 2004).
2. **Sentiment** (sentence level) - two systems compared: VADER vs TextBlob.
3. **Topic** (sentence level) - Linear SVM + TF-IDF, trained on NLTK corpora.

## Contents

| File | Description |
|------|-------------|
| `NLP_Assignment_FINAL_v13.ipynb` | Full notebook: all three tasks, evaluation, and error analysis (run top to bottom). |
| `NER-test.tsv` | Provided NERC test set (10 sentences, 214 token rows, BIO tags). |
| `Sentiment-topic-test.tsv` | Provided sentiment + topic test set (10 sentences). |
| `*.png` | Figures generated by the notebook (confusion matrices, F1 comparison, score scatter). |

## How to run

```
pip install spacy vaderSentiment textblob scikit-learn pandas numpy nltk matplotlib seaborn
python -m spacy download en_core_web_sm
```

Then open `NLP_Assignment_FINAL_v13.ipynb` and run all cells top to bottom. The setup cell also downloads the required NLTK resources automatically.

## Datasets

- Test sets: provided by the course instructors.
- Topic training data: NLTK `movie_reviews` (Pang and Lee, 2004), `gutenberg`, and `brown` corpora.
- NERC: pre-trained spaCy / NLTK models. Sentiment: VADER and TextBlob lexicons (no training data collected).

## Notes

Results are reported on n=10 and are illustrative, not statistically significant; the analysis is primarily qualitative, supported by 5-fold cross-validation of the topic classifier on its training corpus.
